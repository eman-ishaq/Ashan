ASHAN'S BIRTHDAY WORLD — QUICK START

1. Unzip the downloaded file.
2. Open index.html in Chrome to preview the website.
3. Default password: ashan2026
4. To change it, open index.html in a text editor and find:
   const SECRET_PASSWORD = "ashan2026";
   Replace the password with your own.
5. To add photos/videos/music, open the website and use the upload controls.
   Those uploads are browser previews only. To make them visible to Ashan when he opens the shared link on his own phone, place the media files in the website folder and add them to the hosted website, or use a hosting service that supports media uploads.
6. Upload the folder's index.html to a static hosting service to share the website link.

IMPORTANT PRIVACY NOTE:
The password gate in this starter version runs in the browser and is not strong security; a technically experienced person can inspect the HTML. Do not upload sensitive private media publicly. For true password protection, use hosting with server-side password protection/access control.

This is a complete, mobile-friendly starter website with separate sections, an interactive birthday world, story timeline, memory gallery uploads, birthday wishes, mini-games, secret letter, wish candle, music upload, and final surprise.
